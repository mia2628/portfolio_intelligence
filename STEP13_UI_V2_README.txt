STEP13 MOBILE UI v2

목표
- 세련되고 트렌디한 금융앱 느낌
- 모바일 첫 화면에서 Risk / Opportunity / Health를 즉시 확인
- 그 다음 '지금 무엇을 할까'를 가장 강하게 표시
- 자산구성은 도넛 + 비중 막대
- What-if는 실제 포트폴리오와 시각적으로 분리
- 계산근거는 기본 축약, 사용자가 '자세히 보기'를 눌렀을 때 확장

교체 파일
docs/index.html
docs/assets/style.css
docs/assets/app.js

엔진/워크플로/JSON 구조는 변경하지 않음.

적용
1) 위 3개 파일만 동일 경로에 교체
2) Commit
3) GitHub Pages가 자동 반영될 때까지 잠시 기다림
4) 휴대폰에서 새로고침
5) 홈 화면에 추가했다면 앱을 완전히 닫았다가 다시 실행
